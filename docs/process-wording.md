# Approved process wording (do not drift from this on the site)
Chain: AI and software detect, AI drafts proposals, a separate QC agent verifies (the drafting agent never approves its own change; fixed rules plus authoritative evidence for price, stock, SKU, barcode and product identity, otherwise flag, no fix proposed), the customer approves (no approval means no publish, silence is not approval), controlled publish with a saved previous state, post-publish check, report. Rollback always.
Never claim: a person at NYNZ reviews or checks each change; guaranteed results; compliance; any untested integration; unlabelled figures.
Only tested integrations: Shopify product CSV, Google Merchant Center feed, eBay file. All tested on example data locally, never on a live store.
